# 实验四：文件系统与 I/O

## 练习内容

实现 fstat、linkat 和 unlinkat；保证硬链接共享同一 inode 和文件内容，并正确报告链接数。

## 实现

在 easy-fs 的 VFS 层提供稳定 inode 编号、根目录引用计数、硬链接与删除目录项操作。link 检查源文件存在、目标名称合法且未占用，再为同一 inode 写入新目录项；优先复用空目录槽位。unlink 清空匹配的目录项，目录遍历忽略这些空槽，其余名称继续引用原 inode。链接数按根目录中引用该 inode 的有效目录项计算，不改变磁盘 inode 布局，因此与课程提供的镜像生成器兼容。

File trait 增加 stat 方法，OSInode 返回设备号、稳定 inode 号、普通文件类型和当前链接数。fstat 验证 fd 及目标用户内存，把完整初始化的 Stat 结构按页复制到用户缓冲区。未知 fd、非 inode 文件和非法缓冲区返回 -1。

继承前章的时间、内存映射、spawn 和 stride 调度实现。新增 spawn 从文件系统读取 ELF，不再使用静态应用表。

## 验证与边界

官方第六章测试包括基本读写、fstat、多个硬链接共享内容和 inode 编号、逐个 unlink 后的链接数、大量创建/删除，以及既有进程测试。unlink 保留 inode 与数据块，已打开描述符仍可访问内容；最后一个链接删除后的磁盘空间回收为本实现尚未扩展的部分，课程用例明确允许不回收 inode 与数据块。

目录项是名称到 inode 的映射，打开文件描述符还包含独立的偏移和读写模式。删除一个名称不会改变其他硬链接的文件内容。

本地验证结果：官方检查器 31/31，lab1 至 lab4 报告检查通过，命令退出码为 0。文件系统镜像打包工具使用官方兼容 Cargo.lock 固定依赖，避免新依赖超过课程工具链的编译能力。
